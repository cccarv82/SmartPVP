# Screenshots

Drop PNG screenshots here so the main README renders them. Suggested shots
(same filenames the README references):

- `hero.png` — the main hub open (any tab), wide shot.
- `hud.png` — the session HUD (Kills/Deaths/K-D/Streak) with a BG name below.
- `statistics.png` — the Statistics tab.
- `leaderboard.png` — the Leaderboard tab (ideally with a few players synced).
- `matches.png` — the Matches tab with some BG history.
- `rivalries.png` — the Rivalries tab (Preys / Nemeses).
- `winrate.png` — the Win Rate tab.

Tip: take shots at a clean UI scale; 16:9 crops look best in the tables.
